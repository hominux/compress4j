= LZ4

LZ4 needs no extra dependency. It has two formats, so it has two `Compression` factories: `Compression.lz4Framed()` for the `.lz4` files the `lz4` command line tool writes, and `Compression.lz4Block()` for the raw block format.

`Decompressor` detects the framed format, never the block format. Block data passes through `Decompressor.builder(p)` unchanged: use `Decompressor.builder(p, Compression.lz4Block())`. The framed codec has one option, `decompressConcatenated`, to read concatenated frames.

`Decompressor` enforces the default xref:security.adoc[limits]; a stream that expands past a ratio of 100 after the first MiB throws `LimitExceededException`.
