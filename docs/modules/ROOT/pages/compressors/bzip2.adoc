= BZip2

Select bzip2 with `Compression.bzip2()`; `Decompressor` detects it from its magic number.

Options: `blockSize` (1 to 9, in units of 100 KB; default 9) and `decompressConcatenated`.

`Decompressor` enforces the default xref:security.adoc[limits]; a stream that expands past a ratio of 100 after the first MiB throws `LimitExceededException`.
