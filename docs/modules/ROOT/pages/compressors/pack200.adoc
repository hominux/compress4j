= Pack200

Pack200 compresses JAR files into `.pack` files. Select it with `Compression.pack200()`.

Options: `strategy` (`IN_MEMORY` or `TEMP_FILE` buffering) and `properties` (the packer and unpacker properties). The packer loses the content of deflated streamed JAR entries, so write entries `STORED` with size and CRC.

`Decompressor` never detects Pack200, and the tar extractor does not read it. An explicit Pack200 decode runs eagerly in `build()` and extraction limits do not bound it: select it only for trusted input.
