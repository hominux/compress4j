= ARJ

NOTE: Read-only: Compress4J can extract this format but cannot create it.

ARJ support needs no extra dependency. The extractor writes directory and regular file entries and applies the same extraction guards as the other archive extractors: path traversal, symlink policy, and entry and size limits.

Entries from a Unix host that are symbolic links, devices, FIFOs or sockets are skipped and reported to `unsupportedEntryHandler`; nothing is written for them. Entries whose data cannot be read (encrypted or using an unsupported method) fail with an `IOException` that the error handler receives.

If the target already exists and `overwrite(false)` is set, the entry is skipped before it is opened, so the error handler does not see it.
