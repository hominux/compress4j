= 7z

7z is the archive format of the 7-Zip utility. Compress4J creates 7z archives and extracts them, including password-protected ones.

Extraction goes through the same guards as every other format: path traversal is rejected, and `escapingSymlinkPolicy`, `maxEntries`, `maxEntrySize` and `maxTotalSize` apply.

== Notes

* The creator writes to a file path or a `SeekableByteChannel`, because 7z must seek back to patch its header. A channel is written from offset 0.
* The creator does not encrypt. Only extraction accepts a password.
* A symbolic link is stored the way p7zip stores it, as a Unix-mode entry whose content is the link target, and is restored as a symlink on extraction.
* A wrong or missing password fails with an `IOException`.
