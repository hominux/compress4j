= Compress4J

image:https://img.shields.io/maven-central/v/com.hominux/compress4j[Maven Central Version]
image:https://github.com/hominux/compress4j/actions/workflows/ci.yml/badge.svg[Build Status]
image:https://sonarcloud.io/api/project_badges/measure?project=hominux_compress4j&metric=alert_status[Quality Gate Status,link=https://sonarcloud.io/summary/new_code?id=hominux_compress4j]
image:https://sonarcloud.io/api/project_badges/measure?project=hominux_compress4j&metric=coverage[Coverage Status,link=https://sonarcloud.io/summary/new_code?id=hominux_compress4j]

Create and extract archives in Java, with guards against Zip Slip and decompression bombs. Compress4J is a thin
builder-style API on top of
https://commons.apache.org/proper/commons-compress/[Apache Commons Compress], and a maintained successor to
https://github.com/thrau/jarchivelib[JArchiveLib].

* *Safe extraction.* Path traversal (Zip Slip) is rejected, escaping symlinks are rejected by default, and extraction
  has default limits (1,000,000 entries, expansion ratio 100) that stop decompression bombs. See
  <<safe-extraction>>.
* *One API for every format.* Tar, `.tar.gz`, `.tar.bz2`, `.tar.xz`, `.tar.lzma`, `.tar.lz4`, `.tar.zst`, Zip, 7z, AR, CPIO and more share the same builders.
* *Streams.* Read entries as a Java Stream, write from a Stream of files or another archive, repack between formats.
* *Java 21+, JPMS-ready,* published to Maven Central.

== Installation

Requires Java 21 or later.

Gradle:

[source,kotlin]
----
dependencies {
    implementation("com.hominux:compress4j:<version>")

    // Only needed for the .xz, .tar.xz, .lzma and .tar.lzma formats
    implementation("org.tukaani:xz:<version>")

    // Only needed for the .zst and .tar.zst formats
    implementation("com.github.luben:zstd-jni:<version>")

    // Only needed to read Brotli (.br)
    implementation("org.brotli:dec:<version>")
}
----

Maven:

[source,xml]
----
<dependency>
    <groupId>com.hominux</groupId>
    <artifactId>compress4j</artifactId>
    <version>VERSION</version>
</dependency>

<!-- Only needed for the .xz, .tar.xz, .lzma and .tar.lzma formats -->
<dependency>
    <groupId>org.tukaani</groupId>
    <artifactId>xz</artifactId>
    <version>XZ_VERSION</version>
</dependency>

<!-- Only needed for the .zst and .tar.zst formats -->
<dependency>
    <groupId>com.github.luben</groupId>
    <artifactId>zstd-jni</artifactId>
    <version>ZSTD_JNI_VERSION</version>
</dependency>

<!-- Only needed to read Brotli (.br) -->
<dependency>
    <groupId>org.brotli</groupId>
    <artifactId>dec</artifactId>
    <version>BROTLI_DEC_VERSION</version>
</dependency>
----

== Quick start

Create a gzip-compressed tar and extract it:

[source,java]
----
try (TarArchiveCreator creator = TarArchiveCreator.builder(Path.of("example.tar.gz"))
        .compression(Compression.gzip())
        .build()) {
    creator.addDirectoryRecursively(Path.of("exampleDir"));
    creator.addFile(Path.of("path/to/file.txt"));
}

try (TarArchiveExtractor extractor = TarArchiveExtractor.builder(Path.of("example.tar.gz")).build()) {
    extractor.extract(Path.of("outputDir"));
}
----

Compress or decompress a single file with any codec. `Decompressor` detects the codec from the stream. Input with no
detectable signature (deflate, LZMA, LZ4 block, raw Snappy) passes through unchanged, so name those codecs with
`Decompressor.builder(path, Compression.lzma())`:

[source,java]
----
try (Compressor compressor = Compressor.builder(Path.of("file.txt.zst"), Compression.zstd().level(6))
        .build()) {
    compressor.write(Path.of("file.txt"));
}

try (Decompressor decompressor = Decompressor.builder(Path.of("file.txt.zst")).build()) {
    decompressor.write(Path.of("copy.txt"));
}
----

[[safe-extraction]]
== Safe extraction of untrusted archives

Extracting an archive you do not trust? Path traversal, escaping symlinks and decompression bombs are bounded by default: 1,000,000 entries and an expansion ratio of 100 after the first MiB. Add size limits as described in link:.github/SECURITY.md[SECURITY.md]:

[source,java]
----
try (TarArchiveExtractor extractor = TarArchiveExtractor.builder(Path.of("untrusted.tar.gz"))
        .maxEntries(10_000)
        .maxEntrySize(100L * 1024 * 1024)
        .maxTotalSize(1024L * 1024 * 1024)
        .build()) {
    extractor.extract(Path.of("outputDir"));
}
----

Breaching a limit throws `LimitExceededException`. It and `UnsafeEntryException` (traversal, escaping symlinks) both extend `UnsafeInputException`, which an error handler cannot suppress. Raise `maxRatio` for legitimate highly compressible data, or pass `limits(ExtractionLimits.noLimits())` for trusted input.

== Supported formats

AR, CPIO, 7z, ARJ (read-only), UNIX dump (read-only), Deflate, Deflate64 (read-only), BZip2, Brotli (read-only), Gzip, LZ4, LZMA, Pack200, Snappy, Tar (plain, `.tar.gz`, `.tar.bz2`, `.tar.xz`, `.tar.lzma`, `.tar.lz4`, `.tar.zst`, `.tar.Z` read-only), Unix compress (`.Z`, read-only), XZ, Zstandard and Zip.
