= Compress4J

image:https://img.shields.io/maven-central/v/com.hominux/compress4j[Maven Central Version]
image:https://github.com/hominux/compress4j/actions/workflows/ci.yml/badge.svg[Build Status]
image:https://sonarcloud.io/api/project_badges/measure?project=compress4j_compress4j&metric=alert_status[Quality Gate Status,link=https://sonarcloud.io/summary/new_code?id=compress4j_compress4j]
image:https://sonarcloud.io/api/project_badges/measure?project=compress4j_compress4j&metric=coverage[Coverage Status,link=https://sonarcloud.io/summary/new_code?id=compress4j_compress4j]

Create and extract archives in Java, with guards against Zip Slip and decompression bombs. Compress4J is a thin
builder-style API on top of
https://commons.apache.org/proper/commons-compress/[Apache Commons Compress], and a maintained successor to
https://github.com/thrau/jarchivelib[JArchiveLib].

* *Safe extraction.* Path traversal (Zip Slip) is rejected, escaping symlinks are rejected by default, and entry-count and
  size limits stop decompression bombs. See <<_safe_extraction_of_untrusted_archives>>.
* *One API for every format.* Tar, `.tar.gz`, `.tar.bz2`, `.tar.xz`, `.tar.lzma`, `.tar.lz4`, `.tar.zst`, Zip, 7z, AR, CPIO and more share the same builders.
* *Streams.* Read entries as a Java Stream, write from a Stream of files or another archive, repack between formats.
* *Java 21+, JPMS-ready,* published to Maven Central.

== Installation

Requires Java 21 or later.

Gradle:

[source,kotlin]
----
dependencies {
    implementation("com.hominux:compress4j:<version>")

    // Only needed for the .xz, .tar.xz, .lzma and .tar.lzma formats
    implementation("org.tukaani:xz:<version>")

    // Only needed for the .zst and .tar.zst formats
    implementation("com.github.luben:zstd-jni:<version>")

    // Only needed to read Brotli (.br)
    implementation("org.brotli:dec:<version>")
}
----

Maven:

[source,xml]
----
<dependency>
    <groupId>com.hominux</groupId>
    <artifactId>compress4j</artifactId>
    <version>VERSION</version>
</dependency>

<!-- Only needed for the .xz, .tar.xz, .lzma and .tar.lzma formats -->
<dependency>
    <groupId>org.tukaani</groupId>
    <artifactId>xz</artifactId>
    <version>XZ_VERSION</version>
</dependency>

<!-- Only needed for the .zst and .tar.zst formats -->
<dependency>
    <groupId>com.github.luben</groupId>
    <artifactId>zstd-jni</artifactId>
    <version>ZSTD_JNI_VERSION</version>
</dependency>

<!-- Only needed to read Brotli (.br) -->
<dependency>
    <groupId>org.brotli</groupId>
    <artifactId>dec</artifactId>
    <version>BROTLI_DEC_VERSION</version>
</dependency>
----

== Quick start

Create an archive:

[source,java]
----
try (TarGzArchiveCreator creator = TarGzArchiveCreator.builder(Path.of("example.tar.gz")).build()) {
    creator.addDirectoryRecursively(Path.of("exampleDir"));
    creator.addFile(Path.of("path/to/file.txt"));
}
----

Extract one:

[source,java]
----
try (TarGzArchiveExtractor extractor = TarGzArchiveExtractor.builder(Path.of("example.tar.gz")).build()) {
    extractor.extract(Path.of("outputDir"));
}
----

== Safe extraction of untrusted archives

Extracting an archive you do not trust? Path traversal and escaping symlinks are rejected by default. Turn on the remaining guards
for decompression bombs, as described in link:.github/SECURITY.md[SECURITY.md]:

[source,java]
----
try (TarGzArchiveExtractor extractor = TarGzArchiveExtractor.builder(Path.of("untrusted.tar.gz"))
        .maxEntries(10_000)
        .maxEntrySize(100L * 1024 * 1024)
        .maxTotalSize(1024L * 1024 * 1024)
        .build()) {
    extractor.extract(Path.of("outputDir"));
}
----

Breaching a limit throws `ArchiveLimitExceededException`. It and `UnsafeEntryException` (traversal, escaping symlinks) both extend `ArchiveSecurityException`, which an error handler cannot suppress.

== Supported formats

AR, CPIO, 7z, ARJ (read-only), UNIX dump (read-only), Deflate, Deflate64 (read-only), BZip2, Brotli (read-only), Gzip, LZ4, LZMA, Pack200, Snappy, Tar (plain, `.tar.gz`, `.tar.bz2`, `.tar.xz`, `.tar.lzma`, `.tar.lz4`, `.tar.zst`, `.tar.Z` read-only), Unix compress (`.Z`, read-only), XZ, Zstandard and Zip.
